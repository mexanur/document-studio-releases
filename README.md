# Document Studio

Scan, fix, sign and combine documents on your computer. Everything runs offline, and your files never leave the computer.

This page has the Windows installers. The app updates itself from here.

## Download

**[Download the latest version](https://github.com/mexanur/document-studio-releases/releases/latest)**, then under **Assets** pick:

- **Document-Studio-Setup-x.y.z.exe**: installs Document Studio and keeps it up to date (recommended).
- **Document-Studio-x.y.z-portable.exe**: runs without installing, for example from a USB stick. It doesn't update itself.

## Install

1. Run the setup file.
2. If Windows says **"Windows protected your PC"**, choose **More info**, then **Run anyway**. Windows shows this because the app isn't code-signed yet.
3. The first time it opens, enter your licence key. You only do this once on each computer.

## Updates

The installed app checks for a new version shortly after it starts and every six hours. It downloads the update in the background and asks to restart. If you choose Later, the update is installed the next time you quit. To check straight away, use **Help → Check for updates…**.

## The shelf

After activation, a slim tab sits on the right edge of the screen. Drag files from Telegram, mail, the browser or a folder near it, or copy them, and it collects them. You can then combine them into one PDF and drag that straight back into a chat, copy it, save it, or open it in Document Studio. Its settings are under the gear.
